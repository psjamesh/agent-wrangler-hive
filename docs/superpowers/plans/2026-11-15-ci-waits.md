# CI and PR waits

Goal: resolve durable, bounded waits from core's shared PR snapshots and events, with no additional GitHub reads.

Design basis: `docs/investigations/ci-and-deploy-watching.md`, “What waiting on CI should mean”. The coordinator approved all-checks, check-name and merge waits; run, attempt and workflow identity are excluded because core's rollup cannot guarantee them. Core observes linked PRs only.

- [x] Add a focused wait evaluator and reconciler consuming `host.links.prObservation` and `pr:observation`. Subscribe before baseline reads; reconcile persisted waits on startup and the existing refresh sweep. Preserve pending delivery until acknowledgement, flag uncertain/failed wakes, and fence retired runtimes.
- [x] Expose outcomes and observer/deadline/delivery attention through context and watchdog. Bound prose-only suppression using its original anchor, independent of ordinary bead edits.
- [x] Update Hive skills and host/wait documentation. Prove outcomes, head/identity changes, same-head changes, startup recovery, registration races, delivery failures, access boundaries and prose grace with Node tests. Run the required full suite without a browser.
- [ ] Commit, privacy scan, push and open a PR; request tracked adversarial review and hand merge/install delivery to the queen.

A wait authorizes wake and verification only. It never merges, deploys or closes a bead automatically. Missing checks, stale/unavailable observations and missing ownership cannot imply success. Checks-completed, mergeability and merged are separate targets. A wake receipt is persisted before delivery; interrupted or uncertain delivery is flagged rather than blindly resent. Exact wait IDs acknowledge outcomes or retry a failed wake.

Review semantics confirmed by the coordinator: expected-head merge satisfies merge/readiness; check targets retain their evidence requirement and resolve as reconciliation-required when a merged snapshot cannot prove their result. Missing checks remain pending until deadline. Ownership changes flag without ending observation or waking former owners. Terminal evidence wins over expiry; active sends refuse retries. Regression tests exercise each case.
